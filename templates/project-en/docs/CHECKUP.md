# Checklist

Bugs reported but not fixed, and things the owner should try by hand. A fixed item is deleted (its record stays in CHANGELOG).

## To check by hand

Things an automatic test cannot see and the owner should look at once. Each item: where to click, what should be seen.

- [ ] <e.g. "Settings > Theme: are table headers readable in the dark theme">

## Known bugs

Format: symptom · how to reproduce · suspected cause · severity (high/medium/low).

- <e.g. "Title overflows on a long file name · give an 80+ character name · no ellipsis in the title · low">

## Limits

Not bugs, known constraints.

- <e.g. "Files over 2 GB do not open (memory)">
