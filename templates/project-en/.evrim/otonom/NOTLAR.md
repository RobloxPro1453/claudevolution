# Notes (the owner writes, the agent reads at the start of every cycle)

Write anything you want to tell the agent here, **at the bottom**, in a plain sentence. The session does not need to be open; the next cycle reads it. The agent puts `[okundu <date>]` in front of a note it read and writes what it did in OZET. Your objections ("I don't like this", "don't do this") are a measure of evolution: they are counted.

Special words:
- `DUR` alone on a line: the loop stops at the next cycle without doing any work and stays stopped until the line is deleted.
- `ÖNCE: <task>`: goes ahead of the next task.
